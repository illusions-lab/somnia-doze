# Somnia Doze

Doze is the first model in the [Somnia](https://github.com/yourname/somnia) series —
a family of Japanese language models that grow from small beginnings into
larger, more capable versions.

Fine-tuned from [sonoisa/t5-japanese](https://github.com/sonoisa/t5-japanese)
(t5-base-japanese, ~222M parameters).

> うたた寝から、夢は始まる。
